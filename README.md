# EliteFit

EliteFit is a modern and responsive gym website built with React.

The project focuses on creating a professional fitness website with a clean dark theme, orange branding, responsive layouts, and interactive navigation.

## Version 1

Version 1 focuses on the complete frontend UI and responsive website structure.

### Features

- Responsive navigation bar
- Hero section
- Training programs section
- Trainers section
- Contact section
- Footer
- Smooth section navigation
- Responsive desktop, tablet, and mobile layouts
- Interactive navigation links
- Join Now and Explore Programs buttons
- Program and trainer cards
- Contact form UI
- Modern dark and orange theme

## Technologies Used

- React
- JavaScript
- HTML
- CSS
- React Hooks
